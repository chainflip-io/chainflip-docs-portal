# Chainflip JavaScript SDK

## `getChains`

Returns the list of available chains or destination chains for the provided `sourceChain`.

```typescript copy
function getChains(
  sourceChain?: Chain,
  type?: AssetState,
): Promise<ChainData[]>;

type AssetState =
  | "all"
  | "deposit"
  | "destination"
  | "depositChannel"
  | "vaultSwap";

type ChainData = {
  chain: Chain;
  name: string;
  evmChainId: number | undefined;
  isMainnet: boolean;
  requiredBlockConfirmations: number | undefined;
  maxRetryDurationBlocks: number | undefined;
};
```

| Param                    | Description                                                                                               |  Data type   |
| ------------------------ | --------------------------------------------------------------------------------------------------------- | :----------: |
| `sourceChain` (optional) | Chain ID that allows to filter the returned array to contain only destination chains for the given chain. |   `Chain`    |
| `type` (optional)        | Filters the returned chains by the swap capability they support. Defaults to `all`.                       | `AssetState` |

The `type` argument accepts the following values:

| Value            | Description                                                                         |
| ---------------- | ----------------------------------------------------------------------------------- |
| `all`            | Every chain supported by the protocol.                                              |
| `deposit`        | Chains that can be used as a source chain for both deposit channel and vault swaps. |
| `destination`    | Chains that can be used as a destination chain.                                     |
| `depositChannel` | Chains that support [deposit channel swaps](#requestdepositaddressv2).              |
| `vaultSwap`      | Chains that support [vault swaps](#encodevaultswapdata).                            |

If a `sourceChain` is provided, it returns the supported swap destination chains for that specific source chain.

`Chain` is one of `Ethereum`, `Arbitrum`, `Bsc`, `Bitcoin`, `Solana`, `Assethub` or `Tron`.

<Callout type="warning">
  `Polkadot` was removed as a supported chain in version 1.11. Use `Assethub`
  and its `DOT` asset instead.
</Callout>

<details>
<summary>Example</summary>

```typescript copy
import { Chains } from "@chainflip/sdk/swap";

console.log(await swapSDK.getChains(Chains.Assethub));
```

```typescript copy
// console output:

  {
    chain: "Bitcoin",
    name: "Bitcoin",
    evmChainId: undefined,
    isMainnet: true,
    requiredBlockConfirmations: 2,
    maxRetryDurationBlocks: 0,
  },
];
```

## `getAssets`

Fetches the list of available assets for the given `chain`.

```typescript copy
function getAssets(chain?: Chain, type?: AssetState): Promise<AssetData[]>;

type AssetData = {
  /** internal id of the asset, e.g. `SolUsdc` for USDC on Solana */
  chainflipId: ChainflipId;
  asset: Asset;
  chain: Chain;
  contractAddress: string | undefined;
  decimals: number;
  name: string;
  symbol: Asset;
  isMainnet: boolean;
  minimumSwapAmount: string;
  maximumSwapAmount: string | null;
  minimumEgressAmount: string;
};
```

| Param              | Description                                                                         |  Data type   |
| :----------------- | :---------------------------------------------------------------------------------- | :----------: |
| `chain` (optional) | The ID of the chain                                                                 |   `Chain`    |
| `type` (optional)  | Filters the returned assets by the swap capability they support. Defaults to `all`. | `AssetState` |

The `type` argument accepts the same values as the [`getChains`](#getchains) one.

## `getQuoteV2`

Fetches the quotes for swapping tokens based on the provided `quoteRequest` and an `options` argument.
Currently quotes can be either a regular quotes or a DCA quotes.

```typescript copy
function getQuoteV2(
  quoteRequest: QuoteRequest,
  options?: RequestOptions,
): Promise<QuoteResponseV2>;

type QuoteRequest = {
  srcChain: Chain;
  srcAsset: Asset;
  destChain: Chain;
  destAsset: Asset;
  amount: string;
  isVaultSwap?: boolean;
  isOnChain?: boolean;
  brokerCommissionBps?: number;
  brokerAccount?: `cF${string}`;
  affiliateBrokers?: { account: string; commissionBps: number }[];
  ccmParams?: { gasBudget: string; messageLengthBytes: number };
};

type RequestOptions = {
  signal?: AbortSignal;
};
```

| Param                | Description                                                                                  |         Data type          |
| -------------------- | -------------------------------------------------------------------------------------------- | :------------------------: |
| `quoteRequest`       | Object containing the quote request parameters. You can find the interface definition below. |          `Object`          |
| `options` (optional) | Options related to the HTTP request.                                                         | `{ signal?: AbortSignal }` |

The `quoteRequest` object describes the swap for which a quote is returned.

| Param                            | Description                                                                                                                                                                                                                                                                                                   | Data type |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------: |
| `srcChain`                       | Source chain for the swap                                                                                                                                                                                                                                                                                     |  `Chain`  |
| `destChain`                      | Destination chain for the swap                                                                                                                                                                                                                                                                                |  `Chain`  |
| `srcAsset`                       | Asset to be swapped from the source chain                                                                                                                                                                                                                                                                     |  `Asset`  |
| `destAsset`                      | Asset to be received on the destination chain                                                                                                                                                                                                                                                                 |  `Asset`  |
| `amount`                         | Amount of the source token to be swapped, represented in the base unit of the source token                                                                                                                                                                                                                    | `string`  |
| `brokerCommissionBps` (optional) | Commission charged by the broker in basis points. If given, the value will be used instead of the brokerCommissionBps passed when initializing the SDK instance                                                                                                                                               | `number`  |
| `affiliateBrokers` (optional)    | Array of objects describing the affiliate brokers that charge a commission                                                                                                                                                                                                                                    |  `Array`  |
| `isVaultSwap` (optional)         | Flag for requesting a quote for a [vault swap](#encodevaultswapdata). Network related fees can be different for vault swaps compared to channel swaps                                                                                                                                                         | `boolean` |
| `isOnChain` (optional)           | Flag for requesting a quote for an [internal swap](/lp/internal-swaps) that is executed entirely on the State Chain, without a deposit or an egress                                                                                                                                                           | `boolean` |
| `brokerAccount` (optional)       | Chainflip broker SS58 address the quote is attributed to. Overrides the `brokerAccount` option passed when initializing the SDK. Brokers are encouraged to set this so their quotes can be attributed to them                                                                                                 | `string`  |
| `ccmParams` (optional)           | Additional params for requesting a quote for a [CCM swap](/protocol/cross-chain-messaging/overview#type-reference). This is only used to increase the accuracy of the broadcast fee estimation for CCM swaps. A rough estimation of the values is good enough if the actual values are unknown at this stage. | `Object`  |

### Result type

```typescript copy
type QuoteResponseV2 = QuoteRequest & {
  quotes: Quote[];
  /** id of the quote request, include it when reporting an issue with a quote */
  requestId?: string;
};

type Quote = RegularQuote | DCAQuote;

type BoostQuote = NonNullable<Quote["boostQuote"]>;

interface RegularQuote extends QuoteDetails {
  type: "REGULAR";
  /** only present if there is a boost opportunity for the requested swap amount */
  boostQuote?: Omit<RegularQuote, "boostQuote"> & BoostedQuoteDetails;
}

interface DCAQuote extends QuoteDetails {
  type: "DCA";
  dcaParams: {
    numberOfChunks: number;
    chunkIntervalBlocks: number;
  };
  /** only present if there is a boost opportunity for the requested swap amount */
  boostQuote?: Omit<DCAQuote, "boostQuote"> & BoostedQuoteDetails;
}

interface QuoteDetails {
  srcAsset: { chain: Chain; asset: Asset };
  destAsset: { chain: Chain; asset: Asset };
  isVaultSwap: boolean;
  isOnChain: boolean;
  ccmParams?: { gasBudget: string; messageLengthBytes: number };
  depositAmount: string;
  intermediateAmount?: string;
  egressAmount: string;
  includedFees: SwapFee[];
  poolInfo: PoolInfo[];
  /** recommended tolerance to prevent refunds while protecting against big price movements based on current market conditions */
  recommendedSlippageTolerancePercent: number;
  /** recommended live price slippage tolerance to help improve the execution price of a swap based on the global index price. If undefined, live price protection is not available for the asset pair */
  recommendedLivePriceSlippageTolerancePercent: number | undefined;
  /** recommended amount of minutes to retry a swap that has failed to meet the provided slippage tolerance */
  recommendedRetryDurationMinutes: number;
  /** see below */
  lowLiquidityWarning: boolean | undefined;
  /** total estimated time until destination asset is received by the user */
  estimatedDurationSeconds: number;
  estimatedDurationsSeconds: {
    /** estimated time for a deposit to be witnessed */
    deposit: number;
    /** estimated time for a swap to be fully executed */
    swap: number;
    /** estimated time until the output transaction is included in a block */
    egress: number;
  };
  /** estimated price of the swap at amm level (does not include deposit/broadcast fee) */
  estimatedPrice: string;
}

type BoostedQuoteDetails = {
  /** estimated fee (in bps) that the user has to pay (from the deposit amount) to get this swap boosted */
  estimatedBoostFeeBps: number;
  /** maximum boost fee (in bps) that is set on the deposit channel or vault swap */
  maxBoostFeeBps: number;
};

type SwapFee = {
  type: "NETWORK" | "INGRESS" | "EGRESS" | "BROKER" | "BOOST" | "REFUND";
  chain: Chain;
  asset: Asset;
  amount: string;
};

type PoolInfo = {
  baseAsset: { chain: Chain; asset: Asset };
  quoteAsset: { chain: Chain; asset: Asset };
  fee: { chain: Chain; asset: Asset; amount: string };
};
```

<Callout type="info">
  A `boostQuote` is a full quote for the same swap executed through the [boost
  pools](/protocol/boost). Pass it to
  [`requestDepositAddressV2`](#requestdepositaddressv2) or
  [`encodeVaultSwapData`](#encodevaultswapdata) instead of the parent quote to
  boost the swap. It is not nested any deeper: a `boostQuote` has no
  `boostQuote` of its own.
</Callout>

<Callout type="info">
  `lowLiquidityWarning`: This value is true if the difference in the chainflip
  swap rate (excluding fees) is lower than the global index rate of the swap by
  more than a certain threshold (currently set to 5%). This suggets there is not
  enough liquidity in the pool.
</Callout>

<Callout type="info">
  The intermediate amount is the value of the first swap _leg_. In this case,
  BTC > ETH requires both BTC/USDC and USDC/ETH pools (or legs). Learn more
  about Chainflip's [$USDC Denominated
  Pools](/protocol/usdusdc-denominated-pools).
</Callout>

## `requestDepositAddressV2`

Chainflip allows to open a deposit channel for a given set of swap details.
This deposit channel is assigned to a unique address on the source chain of the swap and allows users
to initiate the swap by sending the source asset to this address. Deposit channels expire after a fixed period of time (24hs).

Once a deposit channel is open, the user can send the funds from any wallet to its deposit address to initiate the swap process. **No need to connect a wallet**.
Compared to [vault swaps](/brokers/broker-vault-swaps), using deposit channels can be cheaper for the user because it doesn't require token approvals.

<Callout type="info">
  Learn more about deposit channels in the [Deposit Channels &
  Brokers](/brokers/broker-deposit-channels-swaps) documentation.
</Callout>

Requests a deposit address for the given `DepositAddressRequestV2`.
This method uses the `broker_request_swap_deposit_address` RPC method of the configured [Broker API](/brokers/broker-api/requests#broker_request_swap_deposit_address)
to open a deposit channel.

```typescript copy
function requestDepositAddressV2(
  depositAddressRequest: DepositAddressRequestV2,
): Promise<DepositAddressResponseV2>;

type DepositAddressRequestV2 = {
  quote: Quote | BoostQuote;
  destAddress: string;
  fillOrKillParams: FillOrKillParams;
  srcAddress?: string;
  brokerCommissionBps?: number;
  affiliateBrokers?: {
    account: `cF${string}` | `0x${string}`;
    commissionBps: number;
  }[];
  ccmParams?: CcmParams;
};
```

The `depositAddressRequest` object describes the swap for which a deposit address is requested.

| Param                                                                 | Description                                                                                                                                                                                                              | Data type |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------: |
| `quote`                                                               | The object returned by [getQuoteV2](#getquotev2). This object will be used to set the input and output assets, the DCA parameters (if it is a DCA quote), and the boost parameters (if it is a boost quote).             |  `Quote`  |
| `destAddress`                                                         | Address where the swapped tokens will be sent to on the destination chain.                                                                                                                                               | `string`  |
| [`fillOrKillParams`](/brokers/javascript-sdk/params#fillorkillparams) | Parameters to set a [minimum accepted price](/protocol/swapping-basics#slippage-protection). This protects the swapper against price changes between a quote and the execution of a swap.                                | `Object`  |
| `srcAddress` (optional)                                               | Address that sends the deposit. It is validated against the source chain and simply echoed back in the response.                                                                                                         | `string`  |
| `brokerCommissionBps` (optional)                                      | Commission charged by the [broker](/brokers) creating the channel, in basis points. This option is only available when the SDK is initialized with a `broker` URL                                                        | `number`  |
| `affiliateBrokers` (optional)                                         | An array of objects defining [affiliate accounts](/brokers/broker-affiliates) that take a commission in addition to `brokerCommissionBps`. This option is only available when the SDK is initialized with a `broker` URL |  `Array`  |
| [`ccmParams`](/brokers/javascript-sdk/params#ccmparams) (optional)    | Optional parameters for [passing a message](/protocol/cross-chain-messaging/overview) to a reciever contract/program on the destination chain.                                                                           | `Object`  |

<Callout type="warning">
  The method throws if the `quote` was requested with `isVaultSwap` or
  `isOnChain` set, since neither is executed through a deposit channel. It also
  throws if `ccmParams` is set but the `quote` was requested without
  `ccmParams`, or vice versa.
</Callout>

### Result type

```typescript copy
type DepositAddressResponseV2 = {
  srcChain: Chain;
  srcAsset: Asset;
  destChain: Chain;
  destAsset: Asset;
  amount: string;
  destAddress: string;
  ccmParams?: CcmParams;
  maxBoostFeeBps?: number;
  srcAddress?: string;
  dcaParams?: {
    numberOfChunks: number;
    chunkIntervalBlocks: number;
  };
  fillOrKillParams: FillOrKillParams;
  depositChannelId: string;
  depositAddress: string;
  brokerCommissionBps: number;
  affiliateBrokers: { account: string; commissionBps: number }[];
  depositChannelExpiryBlock: bigint;
  estimatedDepositChannelExpiryTime: number | undefined;
  channelOpeningFee: bigint;
};
```

<Callout type="info">
  The `fillOrKillParams` returned here are the ones that were passed in, not the
  values that were submitted to the protocol. The SDK converts a
  `slippageTolerancePercent` into a minimum price and a `retryDurationMinutes`
  into a number of blocks before submitting them.
</Callout>

### Configure your Broker API

If you want to earn [broker fees](/brokers#broker-fees) or use [affiliates](/brokers/broker-affiliates),
you need to run your own [Broker API](/brokers/running-broker-api).
You can configure the URL of your Broker API when initializing the SDK.

```typescript copy
import { SwapSDK } from "@chainflip/sdk/swap";

const sdk = new SwapSDK({
  network: "perseverance",
  broker: { url: "https://my.broker.io" },
});
```

#### DCA deposit address

Check the [Dollar Cost Average](/protocol/swapping-basics#dollar-cost-average-dca-improving-price) section for more information about the DCA feature.

```typescript copy
import { Chains, Assets } from "@chainflip/sdk/swap";

const { quotes } = await swapSDK.getQuoteV2({
  srcChain: Chains.Ethereum,
  srcAsset: Assets.ETH,
  destChain: Chains.Bitcoin,
  destAsset: Assets.BTC,
  amount: (1.5e18).toString(), // 1.5 ETH
});

// ❗ the dcaV2 feature must be enabled when the SDK is instantiated to receive DCA quotes ❗
const quote = quotes.find((quote) => quote.type === "DCA");
if (!quote) throw new Error("No DCA quote");

const swapDepositAddressRequest = {
  quote,
  destAddress: "bc1qar0srrr7xfkvy5l643lydnw9re59gtzzwf5mdq",
```

## `encodeVaultSwapData`

Vault swaps are initiated by sending a transaction that encodes the details of the swap in the transaction data to the
Chainflip vault on the source chain directly. This allows to initiate swaps without waiting for a deposit address to
be generated.

Vault swap transactions need to encode the swap details in a specific format supported by the protocol. The user
needs to sign and submit this transaction to initiate a swap. Therefore, applications usually require users to
connect their wallet to initiate vault swaps.

Compared to [deposit channel swaps](#requestdepositaddressv2), the vault swap process is similar to the swap process
of other decentralized exchanges and therefore might be easier to integrate into existing applications.

<Callout type="info">
  Learn more about vault swaps in the [Vault Swaps](/brokers/broker-vault-swaps)
  documentation.
</Callout>

Returns the unsigned transaction data for the given `VaultSwapRequest`.
This method uses the `broker_request_swap_parameter_encoding` RPC method of the configured [Broker API](/brokers/broker-api/requests#broker_request_swap_parameter_encoding).

```typescript copy
function encodeVaultSwapData(
  vaultSwapRequest: VaultSwapRequest,
): Promise<VaultSwapResponse>;

type VaultSwapRequest = {
  quote: Quote | BoostQuote;
  destAddress: string;
  fillOrKillParams: FillOrKillParams;
  srcAddress?: string;
  brokerAccount?: `cF${string}`;
  brokerCommissionBps?: number;
  affiliateBrokers?: {
    account: `cF${string}` | `0x${string}`;
    commissionBps: number;
  }[];
  ccmParams?: CcmParams;
  extraParams?: { seed?: `0x${string}` };
};
```

The `vaultSwapRequest` object describes the swap for which the vault swap data is encoded.

| Param                                                                 | Description                                                                                                                                                                                                                                                                                                                             | Data type |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------: |
| `quote`                                                               | The object returned by [`getQuoteV2`](#getquotev2). | `destAddress`                                                         | Address where the swapped tokens will be sent to on the destination chain.                                                                                                                                                                                                                                                              | `string`  |
| [`fillOrKillParams`](/brokers/javascript-sdk/params#fillorkillparams) | Parameters to set a [minimum accepted price](/protocol/swapping-basics#slippage-protection).   host: "https://bitcoin-testnet-rpc.publicnode.com",
```typescript copy
});
```

```typescript copy
  txId: "4403c8d3b752a3aa0757031239a82ce92d67fadc1bb4a35f80ace660499edd55",
  outIndex: 2,
};

  await rpcClient.command("getrawtransaction", inputUtxo.txId),
);
const txFeeSats = 1000n;

  .addInput({
    hash: inputTx.getHash(),
    index: inputUtxo.outIndex,
    nonWitnessUtxo: inputTx.toBuffer(),

    // first output needs to spend assets to deposit address

      txFeeSats,

    publicKey: Buffer.from(keypair.publicKey),
    sign: (hash) => Buffer.from(keypair.sign(hash)),
  })
  .finalizeAllInputs()
  .extractTransaction();
```

## `encodeCfParameters`

It is recommended to encode Vault swaps using the SDK's method to
[encode the Vault Swap data](#encodevaultswapdata). However, some
integrators might want to manually execute the smart contract call to initiate
Vault Swaps.

As documented in the
[encoding-reference](/brokers/vault-swaps-api/encoding-reference), a
`cf_parameters` bytes variable needs to be encoded as part of the Vault Swap
initiation via a smart contract call. While that can be encoded manually, the
SDK provides a method to encode it for convenience.

The `encodeCfParameters` function returns the hex-encoded CF parameters. This method uses the
`broker_encode_cf_parameters` RPC method of the configured

```typescript copy
};

type RequestOptions = {
  signal?: AbortSignal;
};
```

The `SwapStatusRequest` object includes the following arguments:

| Param | Description                                                                                                                                                                                                                                                                  | Data type |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------: |
| `id`  | One of the following:<br/>- The `depositChannelId` returned by [`requestDepositAddressV2`](#requestdepositaddressv2)<br/>- The hash of the transaction that was submitted for a swap encoded with [`encodeVaultSwapData`](#encodevaultswapdata)<br/>- The `swapId` of a swap | `string`  |

### Result type

The response is a discriminated union on the `state` property. Each state adds
the fields that are known at that point of the [swap
lifecycle](#lifecycle-of-a-swap).

```typescript copy
type SwapStatusResponseV2 =
  | ({ state: "WAITING" } & Waiting)
  | ({ state: "RECEIVING" } & Receiving)
  | ({ state: "SWAPPING" } & Swapping)
  | ({ state: "SENDING" } & Sending)
  | ({ state: "SENT" } & Sending)
  | ({ state: "COMPLETED" } & Sending)
  | ({ state: "FAILED" } & Sending);

interface Waiting extends SwapStatusResponseCommonFields {
  /** this state is only possible for swaps with a deposit channel */
  depositChannel: DepositChannelFields;
}

interface Receiving extends SwapStatusResponseCommonFields {
  deposit: DepositFields;
}

interface Swapping extends Receiving {
  swap: SwapFields;
}

interface Sending extends Receiving {
  swap: SwapFields;
  swapEgress: EgressFields | undefined;
  refundEgress: EgressFields | undefined;
  /** egress of a swap that was sent to the refund address after the destination transfer failed */
  fallbackEgress: EgressFields | undefined;
}

interface SwapStatusResponseCommonFields {
  swapId: string;
  /** `Polkadot` is still returned for swaps that were executed before it was removed */
  srcChain: Chain | "Polkadot";
  srcAsset: Asset;
  destChain: Chain | "Polkadot";
  destAsset: Asset;
  destAddress: string;
  depositChannel: DepositChannelFields | undefined;
  ccmParams: CcmParams | undefined;
  fillOrKillParams: FillOrKillParamsWithMinPrice | undefined;
  dcaParams: DcaParams | undefined;
  boost: Boost | undefined;
  /** the broker that opened the channel or encoded the vault swap, followed by its affiliates */
  brokers: Broker[];
  fees: PaidFee[];
  /** total estimated time until destination asset is received by the user */
  estimatedDurationSeconds: number | null | undefined;
  estimatedDurationsSeconds: {
    /** estimated time for a deposit to be witnessed */
    deposit: number;
    /** estimated time for a swap to be fully executed */
    swap: number;
    /** estimated time until the output transaction is included in a block */
    egress: number;
  };
  srcChainRequiredBlockConfirmations: number | null;
  /** timestamp of the last State Chain block that updated this swap */
  lastStatechainUpdateAt: number | undefined;
}

interface Broker {
  account: string;
  commissionBps: string;
}

interface DepositChannelFields {
  id: string;
  createdAt: number;
  depositAddress: string;
  srcChainExpiryBlock: string;
  estimatedExpiryTime: number;
  expectedDepositAmount: string | undefined;
  isExpired: boolean;
  openedThroughBackend: boolean;
  dcaParams: DcaParams | undefined;
}

interface Boost {
  maxBoostFeeBps: number;
  effectiveBoostFeeBps: number | undefined;
  boostedAt: number | undefined;
  boostedBlockIndex: string | undefined;
  /** set when a boost was skipped for lack of boost liquidity, so the deposit waits for full confirmation */
  skippedAt: number | undefined;
  skippedBlockIndex: string | undefined;
}

interface DepositFields {
  amount: string;
  txRef: string | undefined;
  txConfirmations: number | undefined;
  witnessedAt: number | undefined;
  witnessedBlockIndex: string | undefined;
  failure: Failure | undefined;
  failedAt: number | undefined;
  failedBlockIndex: string | undefined;
}

interface SwapFields {
  originalInputAmount: string;
  remainingInputAmount: string;
  swappedInputAmount: string;
  swappedIntermediateAmount: string;
  swappedOutputAmount: string;
  /** average delta between the oracle price and the execution price across all chunks */
  livePriceExecutionDeltaPercentage: number | undefined;
  /** only present for regular (non-DCA) swaps */
  regular: ChunkInfo | undefined;
  /** only present for DCA swaps */
  dca:
    | {
        lastExecutedChunk: ChunkInfo | null;
        /** the chunk that is scheduled but has not been executed yet */
        currentChunk: CurrentChunkInfo | null;
        executedChunks: number;
        remainingChunks: number;
      }
    | undefined;
  /** only present for swaps that were executed on the State Chain */
  onChain:
    | {
        /** the account identifier of the LP for the on-chain swap */
        accountId: string;
        /** undefined if the swap has not been executed or was fully refunded */
        outputAmount: string | undefined;
        /** undefined if no refund occurred */
        refundAmount: string | undefined;
      }
    | undefined;
}

type ChunkInfo = {
  inputAmount: string;
  intermediateAmount: string | undefined;
  outputAmount: string | undefined;
  scheduledAt: number;
  scheduledBlockIndex: string;
  executedAt: number | undefined;
  executedBlockIndex: string | undefined;
  retryCount: number;
  abortedAt: number | undefined;
  abortedBlockIndex: string | undefined;
  abortedReason: ChunkFailureReason | undefined;

  latestSwapRescheduledBlockIndex: string | undefined;
  latestSwapRescheduledReason: ChunkFailureReason | undefined;
};

/** a chunk that has not been executed yet only carries the fields below */
type CurrentChunkInfo = Pick<
  ChunkInfo,
  | "inputAmount"
  | "scheduledAt"
  | "scheduledBlockIndex"
  | "retryCount"
  | "latestSwapRescheduledAt"
  | "latestSwapRescheduledBlockIndex"
  | "latestSwapRescheduledReason"
>;

type ChunkFailureReason =
  | "PriceImpactLimit"
  | "MinPriceViolation"
  | "OraclePriceSlippageExceeded"
  | "OraclePriceStale"
  | "PredecessorSwapFailure"
  | "SafeModeActive";

interface EgressFields {
  amount: string;
  scheduledAt: number | undefined;
  scheduledBlockIndex: string | undefined;
  txRef: string | undefined;
  witnessedAt: number | undefined;
  witnessedBlockIndex: string | undefined;
  failure: Failure | undefined;
  failedAt: number | undefined;
  failedBlockIndex: string | undefined;
  /** only present for egresses that have to be manually submitted by the user */
  transactionPayload:
    | {
        contract: `0x${string}`;
        value: string;
        chainId: string;
        data: `0x${string}`;
      }
    | undefined;
}

interface Failure {
  failedAt: number;
  failedBlockIndex: string;
  mode: string;
  reason: {
    code: string;
    message: string;
  };
}

interface PaidFee {
  type:
    | "NETWORK"
    | "INGRESS"
    | "EGRESS"
    | "BROKER"
    | "BOOST"
    | "REFUND"
    | "LIQUIDITY";
  chain: Chain;
  asset: Asset;
  amount: string;
}
```

## `getSwapLimits`

Fetches the lower and upper bounds for swap amounts.

```typescript copy
function getSwapLimits(): Promise<{
  minimumSwapAmounts: ChainAssetMap<bigint>;
  maximumSwapAmounts: ChainAssetMap<bigint | null>;
}>;

type ChainAssetMap<T> = {
  Bitcoin: { BTC: T };
  Ethereum: { ETH: T; FLIP: T; USDC: T; USDT: T; WBTC: T; CBBTC: T };
  Arbitrum: { ETH: T; USDC: T; USDT: T };
  Solana: { SOL: T; USDC: T; USDT: T };
  Assethub: { DOT: T; USDC: T; USDT: T };
  Bsc: { BNB: T; USDT: T };
  Tron: { TRX: T; USDT: T };
};
```

In order to determine if a swap amount is within the bounds, you can check to
see if the amount is greater than or equal to the minimum swap amount for the
given source asset and chain and less than or equal to the maximum swap amount
for the asset and chain.

These values are in the base unit of the asset, i.e. satoshis for Bitcoin, wei
for Ethereum, and Planck for Assethub, etc.

<Callout type="warning">
  <p>
    Funds sent in excess of the maximum swap amount are absorbed by the protocol
    and cannot be recovered.
  </p>
  <p>
    Funds that fail to meet the minimum swap amount are also absorbed by the
    protocol and cannot be recovered.
  </p>
</Callout>

## `getBoostLiquidity`

Returns the list of available boost pools and their respective depths.
The returned list can be filtered by `feeTierBps` **or** `asset, chain`.

```typescript copy
function getBoostLiquidity(
  params:
    | { feeTierBps?: number }
    | { feeTierBps?: number; asset: Asset; chain: Chain },
): Promise<BoostPoolDepth[]>;

type BoostPoolDepth = {
  feeTierBps: number;
  availableAmount: bigint;
  asset: Asset;
  chain: Chain;
  poolType: "LEGACY_BOOST" | "SUPPLY";
};
```

| Param                     | Description                                                                        |   Data type    |
| ------------------------- | ---------------------------------------------------------------------------------- | :------------: |
| `feeTierBps` (optional)   | Allows filtering of the returned list of boost pools based on their fee tier (bps) |    `number`    |
| `chain, asset` (optional) | Allows filtering of the returned list of boost pools based on their chain asset    | `Chain, Asset` |

`poolType` describes where the liquidity comes from: `LEGACY_BOOST` for the
[boost pools](/protocol/boost), and `SUPPLY` for [lending supply
pools](/lending/supply) that contribute to boosting.

<Callout type="warning">
  `feeTierBps` is deprecated. All boost pools other than the 5 bps one have been
  removed in version 2.2, so `5` is the only accepted value and passing anything
  else throws.
</Callout>

## `getRequiredBlockConfirmations`

Fetches the number of confirmations required by the protocol for each chain.

```typescript copy
function getRequiredBlockConfirmations(): Promise<ChainMap<number | null>>;

type ChainMap<T> = {
  Bitcoin: T;
  Ethereum: T;
  Arbitrum: T;
  Solana: T;
  Assethub: T;
  Bsc: T;
  Tron: T;
};
```

Before a transaction to a deposit address or via smart contract call can be
considered confirmed, it must be included in a certain number of blocks to limit
the risk of a "reorg" event to the protocol. The number of blocks varies by chain. Some chains,
like Assethub, have deterministic finality and do not require any confirmations
other than being included in a block. These chains will return `null` for the
number of confirmations required, while others will return a `number`.
